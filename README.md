## 🎈프로젝트 소개
영어학원에서 매니저 및 스태프들간의 의사소통을 위한 Admin Page 입니다.

## ✨프로젝트 링크
[Admin 페이지](https://culcum-admin-dev.vercel.app/)

## 사용기술
### Frontent
- Vue3
- Pinia
- Vite
- Quasar

### Backend
**Application**
- SpringBoot 3.2.3
  Spring MVC & Security
- JPA
- Querydsl
- Mysql
- Redis

**Test**
- AssertJ
- Mockito
- TestContainer

**Docs**
- Spring rest docs

**Monitoring**
- Spring Acutator
- Prometheus
- Grafana

**Infra**
- Personal Server
- Docker
- Jenkins
- GitHub Actions
